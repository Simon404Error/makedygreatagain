# 让抖音再次伟大

一个面向抖音网页版的 Tampermonkey 用户脚本，基于原作者 WhiteSevs 的开源脚本修改。

## 安装

1. 安装 Tampermonkey。
2. 打开 [`让抖音再次伟大.user.js`](让抖音再次伟大.user.js)，复制全部内容。
3. 在 Tampermonkey 中新建脚本并粘贴保存。
4. 打开或刷新抖音网页，在脚本设置中调整功能。

脚本依赖由原项目提供的 UMD 库，运行时需要联网加载 `@require` 地址。
